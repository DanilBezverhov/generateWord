# DOCX Test & Exam Variant Generator

Консольная утилита на PHP для автоматического парсинга экзаменационных билетов и тестов из документов Microsoft Word (`.docx`), рандомизации вопросов и вариантов ответов, а также генерации уникальных вариантов тестирования.

---

## 📌 Назначение и практическая ценность

Проект решает реальную прикладную задачу автоматизации подготовки к экзаменам и тестированию:
* **Автоматизация рутины:** исключает ручное составление билетов и вариантов из больших текстовых документов Word.
* **Рандомизация:** обеспечивает честное тестирование за счёт случайного перемешивания как самого порядка вопросов, так и вариантов ответа к каждому из них.
* **Гибкая выборка:** позволяет извлечь полный банк вопросов и сгенерировать тест нужного объема (например, ровно 100 случайных вопросов из всего пула).

---

## 🛠 Стек технологий

* **Язык:** PHP 8+
* **Менеджер зависимостей:** Composer
* **Библиотека обработки DOCX:** `phpoffice/phpword`
* **Алгоритмы и логика:** регулярные выражения (RegEx), ассоциативное перемешивание (Fisher–Yates / shuffle)

---

## ⚙️ Как это работает

1. **Загрузка документа:** через `PhpOffice\PhpWord\IOFactory` загружается и парсится файл стандарта Word2007 (`.docx`).
2. **Извлечение текста:** обход всех секций и элементов разметки с получением текстовых блоков.
3. **Парсинг структуры:** регулярным выражением (`/^\d+\./`) отслеживается нумерация вопросов; все последующие строки группируются как варианты ответов.
4. **Рандомизация:**
   * Перемешивается весь пул вопросов (`shuffle`).
   * Внутри каждого вопроса алгоритмически перемешиваются варианты ответов.
5. **Вывод:** формируется чистый и структурированный итоговый вариант теста.

## 🚀 Установка и запуск

1. **Клонировать репозиторий:**
   ```bash
   git clone https://github.com/DanilBezverhov/generateWord.git
   cd generateWord
   ```

2. **Установить зависимости:**
   ```bash
   composer install
   ```

3. **Запустить генерацию:**
   ```bash
   php generate_test.php
   ```
